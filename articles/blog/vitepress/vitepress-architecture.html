项目概述 ​

CRUDClass Blog 是一个基于 VitePress 2.0 的个人技术博客，内容以开发笔记和旅行记录为主。

核心特性 ​

  • 技术栈：VitePress 2.0 + Vue 3.5 + TypeScript 5.9
  • 样式：Tailwind CSS 3.4 + DaisyUI 4.12，亮色与 dracula 暗色双主题
  • 组件：components 目录下的组件自动注册
  • 测试：Vitest 单元测试 + tsc --noEmit 类型检查
  • 代码质量：ESLint + Prettier + TypeScript 严格模式
  • 构建：Vite 构建优化 + 图片压缩

技术栈选择理由 ​

  1. VitePress 2.0.0-alpha.16：基于 Vite 5，支持 Vue 3 组合式 API 和 Markdown 扩展。
  2. TypeScript 5.9.3：编译前做类型检查，编辑器补全也靠它。
  3. Tailwind CSS 3.4.18 + DaisyUI 4.12.24：原子化 CSS 加现成组件类，主题切换由 DaisyUI 提供。
  4. Vitest 4.0.18：复用 Vite 配置，API 与 Jest 兼容。
  5. ESLint + Prettier：前者查代码问题，后者统一格式，都能自动修复。

项目目录结构设计 ​

项目采用 VitePress 标准目录结构，源码放在 src 目录，配置和主题代码放在 .vitepress 目录。

text
CRUDClass-blog/
├── .vitepress/              # VitePress 配置与主题
│   ├── config.mts           # 主配置
│   ├── content-loader.data.ts
│   └── theme/               # 主题目录
├── src/                     # 源码目录
│   ├── articles/            # 文章
│   └── assets/              # 静态资源
├── test/                    # 测试
└── 配置文件                 # tsconfig.json, tailwind.config.js 等

设计理念 ​

  1. 关注点分离：配置与代码分离，主题与内容分离
  2. 模块化设计：组件、hooks、工具函数按目录分组
  3. 可扩展性：易于添加新功能和升级

VitePress 配置详解 ​

config.mts 核心配置 ​

typescript
import { resolve } from 'path'
import { defineConfig } from 'vitepress'
import viteImagemin from 'vite-plugin-imagemin'

export default defineConfig({
  lang: 'zh-CN',
  title: 'CRUDClass BLOG',
  description: '分享日常随笔',
  srcDir: './src',
  base: '/',
  metaChunk: true,
  lastUpdated: true,
  vite: {
    plugins: [
      viteImagemin({
        gifsicle: { optimizationLevel: 7, interlaced: false },
        optipng: { optimizationLevel: 7 },
        mozjpeg: { quality: 80 },
        pngquant: { quality: [0.8, 0.9], speed: 4 },
        svgo: { plugins: [{ name: 'removeViewBox' }] },
      }),
    ],
    resolve: {
      alias: {
        '@vitepress': resolve(__dirname, './'),
        '@theme': resolve(__dirname, './theme'),
        '@components': resolve(__dirname, './theme/components'),
        '@config': resolve(__dirname, './theme/config'),
        '@hooks': resolve(__dirname, './theme/hooks'),
        '@utils': resolve(__dirname, './theme/utils'),
        '@types': resolve(__dirname, './theme/types'),
      },
    },
    build: {
      cssCodeSplit: true,
      sourcemap: false,
      minify: 'esbuild',
    },
  },
  sitemap: {
    hostname: 'https://blog.crudclass.com',
  },
})

总结 ​

这套架构的要点：

  • 页面放 src，配置和主题放 .vitepress，两边不混用。
  • 主题各目录由路径别名固定（@theme、@components、@hooks 等），引用时不必写相对路径。
  • TypeScript 严格模式覆盖 .ts、.mts 和 .vue 的 script 块。
  • 代码检查交给 ESLint，格式交给 Prettier。
