示教-复现（二）：一条控制律同时收敛 x/z/yaw

机器人 ROS2

相机系弧行伺服的控制律推导：两个方位角分工、示教方位角定平衡点、航向符号、比例有界步进、视野守卫与耦合死区，含核心源码

标签：
视觉伺服 控制律 死区补偿
发布于 2026年11月22日

前言 ​

上一篇说明了为什么可以不标定：示教与复现共用同一条测量链，系统误差自己抵消。

测量给的是相机系下的标签坐标 (x, z, yaw) 与示教值之差。控制要做的，是在标签始终不离开画面（横向半视野约 ±35°）的前提下，把三个误差同时压到容差内：横向 3.5 cm、纵向 2.5 cm、航向 1°。

一、为什么不是「转-走-转」 ​

教科书式的做法是转到朝向目标、前进、再转正。实测第一步就崩：转 90° 后标签 100% 出画，接下来 10–15 s 是纯盲走，两次 90° 旋转还会把航向误差放大。

反过来算一下：0.9 m 处 19 cm 的横向偏差只对应 atan(0.19/0.9) ≈ 11.9° 视角，标签本来就在画面里。既然在画面里，就可以边走边转。

二、弧行控制律 ​

相机系下标签的实测坐标 (tx, tz)，设定点 (sp_x, sp_z)，误差 dx = tx - sp_x、dz = tz - sp_z、dyaw 为航向差。控制律只有两行：

text
v = k_rho · ρ · cos(α)  =  k_rho · dz
w = -k_alpha · beta_err  (+ 0.3 · k_yaw · dyaw，同号时才叠加)

其中 ρ = hypot(dx, dz)，α = atan2(dx, dz) 是误差方位角，beta = atan2(tx, tz) 是实测方位角。

两个方位角的分工如下，这里最容易搞错：

角度用途为什么
α = atan2(dx, dz)只决定 v 的方向符号数学上 cos α = dz/ρ，于是 v = k_rho·dz。该退就退，纵向误差说了算
beta = atan2(tx, tz)只驱动 w 的转向项标签在光轴中心时 ≈ 0，位置项自然退出，不会和航向项打架

如果把 w 也写成误差方位角，会踩两个坑：

  1. dz 只剩 2 mm 而 dx 有 1–2 cm 时，atan2(dx, dz) 会虚大到 90°。车其实已经到位，只是航向差 1.7°，控制律却认为「标签在正侧方」，输出满舵。现场表现是 w 在 ±0.12 / ±0.25 之间反复翻转，yaw 卡在 -1.7° 震荡。
  2. 反过来把 v 也换成实测方位角更糟：标签永远在前方（tz > 0），v 恒正，车靠近后该退不退，纵向一路顶到 -31 cm。

三、平衡点必须是「示教方位角」 ​

最初 w 的目标是「把标签拉到画面中心」，即 beta → 0。现场 6 次伺服给出了很干净的对照：

  • golden x ≈ 0 的示教（3 次）全部收敛；
  • |x| > 2 cm 的示教（3 次）全部失败，其中一次卡在 dx = -4.7 cm 整整 26 个迭代。

原因是一行代数：若平衡点是 beta = 0，则 dx 的平衡值恒等于 -golden_x。手推示教时 golden x = +4.9 cm 再正常不过，于是误差永远停在 -4.9 cm，超出 3.5 cm 容差。

修复只有一处：转向目标改成示教方位角 beta_g = atan2(sp_x, sp_z)，即

python
beta_g = math.atan2(tx - dx, tz - dz)      # 由实测值反解设定点
beta_err = norm_rad(math.atan2(tx, tz) - beta_g)
w_alpha = -k_alpha * beta_err              # golden 位姿处自然为 0

语义从把标签摆到画面中心，变成把标签摆回示教时的偏移。控制目标因此和示教时的位姿一致，而不是画面中心。

四、航向项的符号 ​

严格按几何推一遍。车左转 θ（w > 0）时，标签在相机系里的 yaw 变化是 -θ，所以 dyaw = -θ：

text
dyaw < 0  ⟺  车已偏左  ⟺  需要右转（w < 0）
⇒  w = +k_yaw · dyaw

原实现写的是 w = -k_yaw · dyaw，方向恒反。现场日志：dyaw = -1.67° → w = +0.12（左转）→ dyaw 变得更负（-1.86°），dx 从 2.1 cm 甩到 7.5 cm，三次测试全部发散。

同一个符号错误还在横向平移的写法里出现过一次（车朝标签反方向走），最后是拿一份参考实现的「标签在画面右侧 → 角速度取负」交叉验证才定位。符号问题靠日志里的方向确认，不靠直觉。

五、比例有界步进 ​

定步长是过冲的根源。早先用固定 0.35 s 开环弧行：w = 0.12 rad/s × 0.35 s = 2.4°，比 ±1° 的航向容差还大，于是「纠正—过冲—反向纠正」永远在震荡；同一段代码里 v 被死区强抬到 0.04 m/s，标签在正侧方时仍强制前进 1.4 cm，纵向一路超前。

改成按余差比例计算每步的位移预算：

text
d_lin = clamp(0.5 · |dz|, 3 mm, 30 mm)
d_ang = clamp(0.5 · (|beta_err| + |dyaw|), 0.2°, 4°)
dur   = clamp(min(d_lin/|v|, d_ang_rad/|w|), 0.06 s, 0.60 s)

三个约束同时生效：

  • 每步最多吃掉一半余差，单调收敛不过冲；
  • 时长由先到者决定，线位移和角位移谁先满足谁停；
  • 角预算只在确实需要转时才非零（|dyaw| > 容差 或 |beta_err| > 3°）。这一条是后来补的：远距场景里 dyaw 已经到位（0.5°），角预算被钳到 0.07°，dur = 0.06 s，每步只走 0.48 cm，60 次迭代走不完 0.6 m。置零后每步 3 cm，快 6 倍。

完整实现如下（参数对象 p 承载增益与全部阈值）：

python
def compute_bounded_step(dx, dz, dyaw, tx, tz, p):
    """返回 (v, w, dur)：本步修正量被限制在余差的一半以内。"""
    fwd, rgt = dz, dx
    rho = math.hypot(fwd, rgt)
    in_pos = abs(dx) <= p.tol_lateral and abs(dz) <= p.tol_range

    alpha = math.atan2(rgt, fwd)                 # 误差方位角：只管 v 的符号
    beta = math.atan2(tx, tz)                    # 实测方位角：只管转向与视野
    beta_g = math.atan2(tx - rgt, tz - fwd)      # 示教位姿处的实测方位角
    beta_err = norm_rad(beta - beta_g)

    # 位置已接近到位、航向是主导误差 -> 只转不走。
    # 否则 alpha 项(修 dx) 与 yaw 项(修 dyaw) 会互相打架，形成极限环。
    yaw_dominant = (abs(dyaw) > p.tol_yaw
                    and abs(dx) < 3.0 * p.tol_lateral
                    and abs(dz) < 3.0 * p.tol_range)

    if in_pos or yaw_dominant:
        v = 0.0
        w = 0.0 if abs(dyaw) <= p.tol_yaw else p.k_yaw * math.radians(dyaw)
    else:
        v = p.k_rho * rho * math.cos(alpha)      # 恒等于 k_rho * dz
        w_alpha = -p.k_alpha * beta_err
        w_yaw = p.k_yaw * math.radians(dyaw) * p.yaw_weight_moving
        # 两项反向时方位角项优先：旋转不改变位置项之和，
        # 让它对冲只会把车漂离示教射线（航向由 yaw_dominant 收尾）
        w = w_alpha + (w_yaw if w_alpha * w_yaw >= 0.0 else 0.0)
        if abs(dz) <= p.tol_range:               # 纵向到位就别再前进
            v = 0.0
        if abs(math.cos(beta)) < p.arc_boost_cos_min:   # 标签在正侧方 = 纯旋转
            v = 0.0

    v = clamp(v, -p.arc_max_v, p.arc_max_v)
    w = clamp(w, -p.arc_max_w, p.arc_max_w)

    # ---- 位移预算：线预算只看纵向 |dz|，横向靠旋转消除 ----
    d_lin = max(0.0, min(p.step_lin_max, p.step_frac * abs(dz)))
    if in_pos or yaw_dominant:
        d_ang = clamp(p.step_frac * abs(dyaw),
                      p.step_ang_min, p.step_ang_max) if abs(dyaw) > p.tol_yaw else 0.0
    elif abs(dyaw) > p.tol_yaw or math.degrees(abs(beta_err)) > p.ang_need_deg:
        d_ang = clamp(p.step_frac * (math.degrees(abs(beta_err)) + abs(dyaw)),
                      0.0, p.step_ang_max)
    else:
        d_ang = 0.0
    if d_lin > 0.0:
        d_lin = max(d_lin, p.step_lin_min)
    if d_ang > 0.0:
        d_ang = max(d_ang, p.step_ang_min)

    # ---- 死区补偿：只在真有位移需求时抬，且只抬纯旋转步的 w ----
    if d_lin > 0.0 and abs(dz) > p.tol_range and 0.0 < abs(v) < p.min_linear:
        v = math.copysign(p.min_linear, v)
    if d_ang > 0.0 and abs(v) < 1e-6 and 0.0 < abs(w) < p.min_angular:
        w = math.copysign(p.min_angular, w)

    # ---- 时长：线/角先到者，再夹到 [time_min, time_max] ----
    dur = float("inf")
    if d_lin > 0.0 and abs(v) > 1e-6:
        dur = min(dur, d_lin / abs(v))
    if d_ang > 0.0 and abs(w) > 1e-6:
        dur = min(dur, math.radians(d_ang) / abs(w))
    if not math.isfinite(dur):
        return v, w, 0.0
    dur = clamp(dur, p.step_time_min, p.step_time_max)

    # ---- 视野守卫：旋转会让标签更偏出画面时，截短或收缩 ----
    if abs(w) > 1e-6 and (abs(tx) > 1e-4 or abs(tz) > 1e-4):
        theta = math.degrees(math.atan2(tx, tz))          # 用实测方位角，不是误差
        if abs(theta) > 1e-4 and math.copysign(1.0, w) == math.copysign(1.0, theta):
            allowed = p.fov_half_deg - p.fov_margin_deg - abs(theta)
            if allowed <= 0.0:
                w = 0.0                                   # 已贴边缘，本步不转
            else:
                allowed_dur = math.radians(allowed) / abs(w)
                if allowed_dur < p.step_time_min:
                    # 不用「把 dur 拉回下限」——那会让实际转角突破视野上限
                    w = math.copysign(math.radians(allowed) / p.step_time_min, w)
                    dur = p.step_time_min
                else:
                    dur = min(dur, allowed_dur)
    return v, w, dur

六、视野守卫与耦合死区 ​

视野守卫的关键是参数要用实测方位角 atan2(tx, tz)，而不是误差方位角 atan2(dx, dz)。后者在 dz 很小时会虚大（dz=2 mm 时能到 84°），把一次正确的原地旋转误判成「向外转」而强制 w = 0，伺服就此冻结到超时。

耦合死区是另一种卡死：纵向已到位（|dz| ≤ 2.5 cm），横向超差（|dx| > 3.5 cm）。纯旋转 dθ 会同时让 dx 变化 z·dθ、dyaw 变化 -dθ，是 1:-1 的反向耦合：修平横向必然破坏航向（例：0.8 m 处 4.7 cm 需转 3.4°，航向随之超差），而 v 又被纵向容差置零，于是 v = 0, w ≈ 0, dur = 0，原地不动。

正确的处理是直线倒退 0.12 m 脱离该状态再重新接近（直线里程计可靠，横向不可靠），最多 3 次，仍不收敛就干净失败：

python
def is_coupled_stall(dx, dz, p):
    """纵向到位、横向超差：任何旋转都救不了，只能退出去重来。"""
    return abs(dz) <= p.tol_range and abs(dx) > p.tol_lateral

七、收敛判据与实测 ​

三轴同时进容差（横向 3.5 cm、纵向 2.5 cm、航向 1°），且需要连续 3 个新 seq 都满足才判成功：

python
if ok:
    if tag.seq != last_seq:        # 同一帧不重复计数
        last_seq = tag.seq
        stable += 1
    if stable >= stable_samples:
        return True
else:
    stable = 0                     # 任何一轴出界立即归零
    last_seq = -1
